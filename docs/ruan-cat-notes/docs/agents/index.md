## chat.z.ai

- 智谱： https://chat.z.ai/

- 有云 linux 环境。
- 有免费额度，可以高强度白嫖。
- 有能够直接读取并使用 MCP 的内部 linux 工具。
- 不能中途切换模型。一旦模型流量限额，就不得不卡顿停滞了。很影响任务开发。
- 可以考虑快速初始化 skills 和 MCP，进而继续高强度完成基于 pr 的开发任务。
- 每个会话有生命周期，存续时间预期 2 个小时。在设置页面看。

## chatglm.cn

- 智谱： https://chatglm.cn/

- 没有可以执行 MCP 的 agent 客户端。无法批量安装 MCP 配置。
- 有云端 linux 系统。但是必须要主动开启 agent 选项才行。
- 在长任务表现内，出现工具链自动丢失的情况，之前安装的环境和包会自动被清空。
- 每天赠送的 200 积分额度很少，完全不能支持一个较长一点的，基于 github pr 的云任务。
